# Security

Please report a vulnerability privately, through GitHub's
[private vulnerability reporting](https://github.com/kphutt/explorables/security/advisories/new)
for this repository, not in a public issue or pull request.

Say what you found, where (the page or file, and the URL if it is live), and how to reproduce
it. You will get a reply, and a fix or an explanation, as soon as it can be looked at.

In scope: anything served from `explorables.kphutt.com`, its response headers, and this
repository's build, checks and deploy workflows. The main site, `kphutt.com`, has its own
repository and its own report link.
